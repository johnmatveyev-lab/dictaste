# Developer free setup

Unlock **unlimited** Dictaste polish using **your** LLM API key. We verify you starred this repo.

## Prerequisites

- GitHub account
- OpenAI-compatible API key (OpenAI, or any OpenAI-compatible endpoint)
- Mac (14+) and/or Windows 10/11

## Steps

### 1. Star this repository

On GitHub: open [johnmatveyev-lab/dictaste](https://github.com/johnmatveyev-lab/dictaste) → click **★ Star**.

### 2. Create a Dictaste account

Go to: https://dictaste.vercel.app/developers/setup  

Sign in (email or GitHub OAuth if enabled).

### 3. Verify the star

1. Enter your **GitHub username** (exactly as on GitHub)
2. Click **Verify star & unlock**
3. Copy your **license key** (`dt_live_…`)

If verification fails:

- Confirm the star is on **johnmatveyev-lab/dictaste** (not a fork)
- Wait a few seconds and retry (GitHub API lag)
- Username must match the account that starred

### 4. Install the app

- **macOS:** [INSTALL_MAC.md](./INSTALL_MAC.md)
- **Windows:** [INSTALL_WINDOWS.md](./INSTALL_WINDOWS.md)

### 5. Connect license + your key

1. Open Dictaste → **Account & Settings**
2. Paste **license key**
3. Paste **your** OpenAI (or compatible) API key  
4. Save · enable AI polish  
5. Dictate (Mac: hold **fn**) or use Windows hotkey **Ctrl+Shift+Space**

## Privacy note

- Speech recognition on Mac is on-device by default  
- Managed polish sends **text only** (never audio) when using our models  
- Developer BYO keys: polish text goes to **your** provider under **your** account
